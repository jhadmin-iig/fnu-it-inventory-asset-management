# FNU IT Inventory and Asset Management System

Static browser-based inventory and asset management system for the Fiji National University Division of IT Services.

## Included

- Asset register for fixed, non-fixed, serialised, consumable, and software assets
- Campus, building, room, lab, store, and custodian tracking
- Receiving, stores, movement, maintenance, disposal, audit, licence, reporting, and admin pages
- Local browser persistence with JSON backup and CSV exports
